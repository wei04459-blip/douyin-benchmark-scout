# 搜索可靠性契约

## 假空识别

抖音搜索可能出现进程退出码为 0、返回数组却为空的情况。只按退出码判断会把平台限制误认为“关键词没有内容”。

必须执行以下规则：

1. 搜索阶段默认使用可见浏览器，详情与下载可使用无头模式。
2. 每个关键词独立检查有效作品 ID 数，不能只看进程退出码。
3. 空结果等待后换同义写法重试；不得用宽泛根词冒充精确关键词结果。
4. 接口仍为空时，使用已登录的真实搜索页面兜底，并记录 `search_channel`。
5. 仍达不到最低结果数时立即熔断。整批不出表、不移动游标，保留检查点。
6. 同日成功关键词写入独立检查点，恢复时只补失败关键词。

## 配额和状态

- `--per-keyword N` 是硬配额；任何关键词不足 N 条，整批失败。
- `seen_aweme_ids` 只代表见过；`processed_aweme_ids` 只代表已完成转录、分析、工作簿和安全清理。
- 缺粉丝数的作品标记待核验，不能进入 S/A。
- 重复作品必须刷新公开指标与分析，不能静默跳过。

## 删除门槛

仅当以下条件全部满足时删除原视频：

- 视频已成功转录且口播稿存在；
- AI 分析字段完整；
- 工作簿保存成功并能重新打开；
- 表头契约、重点账号表和错误扫描通过；
- 删除目标是本批运行目录中的明确视频文件。
