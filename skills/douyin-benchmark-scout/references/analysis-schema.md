# 竞品分析字段契约

`AI拆解模板.json` 的每个作品必须填写：

| 字段 | 内容要求 |
|---|---|
| `track` | 内容方向或赛道 |
| `topics` | 3–8 个可检索关键词，可为空时从标题标签提取 |
| `type` | 教程、案例、观点、避坑、挑战、清单等选题类型 |
| `topic_summary` | 一句话说明这条视频在解决什么问题 |
| `hook` | 记录真实开头语句，并说明钩子模式；不要虚构原话 |
| `structure` | 按出现顺序拆解内容段落与节奏 |
| `emotion` | 好奇、焦虑、收益期待、反差、认同等情绪变化 |
| `summary` | 摘要，并标注口播中无法验证的主张与事实边界 |
| `viral` | 用数据、账号基本盘与表达共同解释传播，不只看点赞绝对值 |
| `migration` | 结合用户提供的账号定位，给出可迁移角度；没有定位时写通用迁移思路 |

先分析 S，再分析 A，然后处理 B/C。禁止补写视频没有出现的经历、收入、工具效果或因果关系。
