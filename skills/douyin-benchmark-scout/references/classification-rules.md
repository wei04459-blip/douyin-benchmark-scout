# 爆款分级规则

默认阈值可在配置中修改：

- S｜低粉高爆：粉丝不超过 10 万、单条至少 1 万赞、赞粉比不低于 100%。
- A｜重点观察：粉丝不超过 30 万、单条至少 3 万赞、赞粉比不低于 30%。
- C｜大号常规流量：粉丝至少 100 万且赞粉比低于 10%。
- B｜常规样本：其余已取得粉丝数据的作品。
- 待补粉丝数：缺少公开粉丝数，不进入 S/A。

计算：

- 赞粉比 = 视频点赞 ÷ 账号粉丝数。
- 互动/粉丝比 =（点赞 + 评论 + 收藏 + 转发）÷ 账号粉丝数。
- 初筛分 = 点赞 + 收藏 + 2 × 评论 + 转发。

等级是选题研究优先级，不是对账号或内容质量的价值判断。
